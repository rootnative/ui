# AppBar

Top app bars display navigation, title, and actions at the top of the screen.
Follows the [Material Design 3 Top App Bar](https://m3.material.io/components/top-app-bar/overview) specification.

## Usage

<SnackExample
  name="RootNative AppBar — Usage"
  code={`
  import { AppBar } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { View } from 'react-native'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1 }}>
            <AppBar title="Home" />
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

## Variants

| Variant | Description |
|---------|-------------|
| `small` | Compact single-row bar (default) |
| `center-aligned` | Title centered in the bar |
| `medium` | Expanded two-row bar |
| `large` | Expanded with larger title typography |

## In a Modal

A modal closes, so it shows a cross, not a back arrow. Set
`navigationIcon="close"`. The button keeps the built-in size, colour, and
position, and it announces "Close" to screen readers. `onBackPress` fires for
both icons.

<SnackExample
  name="RootNative AppBar — Close Button"
  code={`
  import { AppBar } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { Alert, View } from 'react-native'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1 }}>
            <AppBar
              title="About"
              canGoBack
              navigationIcon="close"
              onBackPress={() => Alert.alert('Close pressed')}
            />
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

For any other leading control, pass it to `leading`. The bar centres custom
`leading` and `trailing` content on the title, so an `IconButton` needs no
wrapper.

## With a Subtitle

`subtitle` adds one line of supporting text under the title. Its color is
`onSurfaceVariant`. Its type role follows the variant:

| Variant | Subtitle role | Bar height |
|---------|---------------|------------|
| `small`, `center-aligned` | `labelMedium` | 64dp, no change |
| `medium` | `labelLarge` | 112dp → 136dp |
| `large` | `titleMedium` | 152dp → 184dp |

The roles and the growth come from the MD3 Expressive flexible app bars. The
baseline `medium` and `large` bars have no subtitle in the spec, so they take
the subtitle of the flexible bars and keep their own title.

`contentColor` does not change the subtitle color. Use `subtitleStyle` for
that. On the `primary` and `primaryContainer` schemes, the subtitle takes the
scheme's content color.

<SnackExample
  name="RootNative AppBar — Subtitle"
  code={`
  import { AppBar } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { View } from 'react-native'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1, rowGap: 16 }}>
            <AppBar
              title="Inbox"
              subtitle="3 unread"
              actions={[{ icon: 'magnify', accessibilityLabel: 'Search' }]}
            />
            <AppBar
              title="Processes"
              subtitle="The list updates every 3 seconds."
              variant="medium"
            />
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

## Collapse on Scroll

The `medium` and `large` variants collapse to the small (64dp) form as the
content scrolls, per the MD3 spec: the container height shrinks, the title
transitions to `titleLarge` typography, and the on-scroll tonal shift is
applied automatically — no `elevated` toggling needed.

Wire it up with `useScroll` from `@rootnative/inertia`: pass `scrollY` to the
bar's `scrollOffset` prop and the matching `onScroll` to a
`Motion.ScrollView`. Everything runs on the UI thread — there is no JS-side
scroll listener.

<SnackExample
  name="RootNative AppBar — Collapse on Scroll"
  code={`
  import { AppBar, Typography } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { Motion, useScroll } from '@rootnative/inertia'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { View } from 'react-native'

  function Screen() {
    const { scrollY, onScroll } = useScroll()

    return (
      <View style={{ flex: 1 }}>
        <AppBar title="Large App Bar" variant="large" scrollOffset={scrollY} />
        <Motion.ScrollView
          onScroll={onScroll}
          scrollEventThrottle={16}
          contentContainerStyle={{ padding: 16, rowGap: 16 }}
        >
          {Array.from({ length: 30 }, (_, i) => (
            <Typography key={i}>Scroll content row {i + 1}</Typography>
          ))}
        </Motion.ScrollView>
      </View>
    )
  }

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <Screen />
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

The bar collapses over a scroll distance equal to the height it loses
(48px for `medium`, 88px for `large`), so the motion tracks the finger 1:1.
With a `subtitle`, the bar is taller, so the distance is 72px for `medium` and
120px for `large`. The subtitle collapses to `labelMedium` with the title.
`scrollOffset` is ignored by the `small` and `center-aligned` variants —
keep using `elevated` for those.
