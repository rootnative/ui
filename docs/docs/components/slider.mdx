# Slider

A slider lets the user select a value, or a range of values, from a continuous or discrete set.
It follows the [Material Design 3 Slider](https://m3.material.io/components/sliders/overview) specification.

The component supports four MD3 configurations from one API:

- **Continuous**: one thumb, any value in the range
- **Discrete**: one thumb that snaps to a `step`, with tick marks that the component renders
- **Range**: two thumbs (`value={[low, high]}`)
- **Centered**: the active track fills from the midpoint to the thumb, for a symmetric value such as a balance

## Usage

<SnackExample
  name="Root Native Slider — Usage"
  code={`
  import { Slider } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { useState } from 'react'
  import { View } from 'react-native'

  export default function App() {
    const [value, setValue] = useState(0.4)
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1, justifyContent: 'center', padding: 24 }}>
            <Slider value={value} onValueChange={(v) => setValue(v as number)} />
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

## Range

Pass a `[low, high]` tuple for a range slider with two thumbs. Both thumbs obey `step` when you set it.

<SnackExample
  name="Root Native Slider — Range"
  code={`
  import { Slider, Typography } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { useState } from 'react'
  import { View } from 'react-native'

  export default function App() {
    const [range, setRange] = useState([25, 75])
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1, justifyContent: 'center', padding: 24, gap: 12 }}>
            <Slider
              value={range}
              onValueChange={(v) => setRange(v)}
              minimumValue={0}
              maximumValue={100}
              showValueLabel="always"
            />
            <Typography variant="bodySmall">
              {Math.round(range[0])} – {Math.round(range[1])}
            </Typography>
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

Each thumb is its own control for a screen reader and for the keyboard. A screen reader user moves each thumb with its own adjust gesture, and on the web Tab moves from one thumb to the other. The thumbs read "Minimum" and "Maximum" by default. Change them with `startThumbAccessibilityLabel` and `endThumbAccessibilityLabel`. When you also pass `accessibilityLabel`, each thumb reads both labels, for example "Runtime, Shortest".

```tsx
<Slider
  accessibilityLabel="Runtime"
  startThumbAccessibilityLabel="Shortest"
  endThumbAccessibilityLabel="Longest"
  value={runtime}
  onValueChange={(v) => setRuntime(v)}
  minimumValue={60}
  maximumValue={180}
/>
```

## Centered

Pass `centered` for a slider whose active track fills out from the midpoint, not from the start. Use it for a symmetric value such as a balance, an EQ band, or a zoom adjustment.

  import { useState } from 'react'
  import { View } from 'react-native'

    const [balance, setBalance] = useState(0)
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>

## Value label

By default, the value-label bubble appears above the active thumb during a drag. Pass `'always'` to keep it visible, or `false` to hide it. Use `formatValueLabel` to change the displayed string.

```tsx
<Slider value={value} onValueChange={setValue} showValueLabel="always" />

<Slider
  value={price}
  onValueChange={setPrice}
  minimumValue={0}
  maximumValue={1000}
  step={10}
  formatValueLabel={(v) => `$${v}`}
/>
```

## Custom colors

`containerColor` overrides the active track, `contentColor` overrides the thumb, and `inactiveTrackColor` overrides the inactive track. The ticks and stop indicators on the active segment stay `onPrimary`, as MD3 specifies. They don't derive from these overrides. The MD3 disabled treatment stays in place, whatever you override.

## Controlled vs uncontrolled

Pass `value` for a controlled slider: you own the state, and each change comes through `onValueChange`. Omit `value` and pass `defaultValue` for an uncontrolled slider that keeps its own state.

```tsx
// Controlled
<Slider value={value} onValueChange={setValue} />

// Uncontrolled — pass `[low, high]` to enable range mode
<Slider defaultValue={[20, 80]} onSlidingComplete={(v) => console.log(v)} />
```

`onValueChange` fires continuously during a drag. `onSlidingComplete` fires once, when the user releases the thumb. Use it to commit an expensive update (a network call, a large recompute) only on release.

## Accessibility

The track has `accessibilityRole="adjustable"`. It sets `accessibilityValue` with `min`/`max`/`now`, rounded to integers, because the native accessibility APIs require integer values, and with a formatted `text` field that a screen reader reads aloud. Pass `accessibilityLabel` to say what the slider controls.

```tsx
<Slider
  value={volume}
  onValueChange={setVolume}
  accessibilityLabel="Output volume"
/>
```
