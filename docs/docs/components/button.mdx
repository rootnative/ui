# Button

Buttons help people take actions and make choices with one tap.
The component follows the [Material Design 3 Button](https://m3.material.io/components/buttons/overview) specification.

## Usage

<SnackExample
  name="Root Native Button — Usage"
  code={`
  import { Button } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { View } from 'react-native'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1, alignItems: 'center', justifyContent: 'center', padding: 16 }}>
            <Button variant="filled" onPress={() => console.log('pressed')}>
              Save
            </Button>
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

|---------|----------|

| `elevated` | Elevated surface, medium emphasis |
| `outlined` | Secondary action, medium emphasis |
| `text` | Low emphasis, often in dialogs |

## With Icons

`leadingIcon` and `trailingIcon` accept three forms: a string name (resolved through the `iconResolver` of the theme, for example `mdiResolver` for [MaterialDesignIcons](https://pictogrammers.com/library/mdi/)), a pre-rendered React element from any icon library, or a render function that receives the resolved `{ size, color }`. See the [Icons guide](../icons) for the details, including how to register a global `iconResolver` for Lucide, SF Symbols, or custom SVGs.

<SnackExample
  name="Root Native Button — Icons"
  code={`
  import { Button } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { View } from 'react-native'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1, justifyContent: 'center', padding: 16, gap: 12 }}>
            <Button leadingIcon="plus" onPress={() => {}}>Add Item</Button>
            <Button trailingIcon="arrow-right" onPress={() => {}}>Continue</Button>
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

### Bring your own icon library

Pass any element directly. This helps for a one-off icon, or when you want full control over the size and the color:

```tsx
import { Button } from '@rootnative/components'
import { Check, ArrowRight } from 'lucide-react-native'

<Button leadingIcon={<Check size={18} color="#fff" />}>Save</Button>
<Button trailingIcon={<ArrowRight size={18} color="#fff" />}>Continue</Button>
```

Or use a render function. It receives the icon size and color that the button
resolved from its `size`, its `variant` and its current state, so the icon
follows them without hard-coded values:

```tsx
<Button leadingIcon={({ size, color }) => <Check size={size} color={color} />}>
  Save
</Button>
```

`iconSize` and `contentColor` override what the function receives, if you need
to depart from the resolved values:

```tsx
<Button
  leadingIcon={({ size, color }) => <Check size={size} color={color} />}
  iconSize={20}
  contentColor="#fff"
>
  Save
</Button>
```

## Toggle

A toggle button turns an option on or off, for example bold text in an
editor. Use `selected` with `onSelectedChange` for a controlled toggle. Use
`defaultSelected` for an uncontrolled toggle: the button flips its own state
on press and reports the new state through `onSelectedChange`.

A selected toggle takes the selected colors of its variant, and its shape
changes: a `round` button turns square, and a `square` button turns round.
The `filled`, `tonal`, `outlined` and `elevated` variants have a toggle. MD3
has no text toggle, so a `text` button ignores these props.

<SnackExample
  name="Root Native Button — Toggle"
  code={`
  import { Button } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { useState } from 'react'
  import { View } from 'react-native'

  export default function App() {
    const [isBold, setIsBold] = useState(false)
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1, justifyContent: 'center', padding: 16, gap: 12 }}>
            <Button leadingIcon="format-bold" selected={isBold} onSelectedChange={setIsBold}>
              Bold
            </Button>
            <Button variant="tonal" leadingIcon="format-italic" defaultSelected={false}>
              Italic
            </Button>
            <Button variant="outlined" shape="square" leadingIcon="format-underline" defaultSelected>
              Underline
            </Button>
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

`containerColor` and `contentColor` apply in both states. To color the two
states differently, control the toggle and pass a color for each state:

```tsx
<Button
  selected={isBold}
  onSelectedChange={setIsBold}
  containerColor={isBold ? '#6750A4' : '#E8DEF8'}
  contentColor={isBold ? '#FFFFFF' : '#1D192B'}
>
  Bold
</Button>
```

## Loading

Set `loading` while the action runs. The button shows an indeterminate
`CircularProgress` in place of the leading icon, at the icon size and in the
label color. It ignores presses, shows no hover or press state, and sets
`aria-busy`. It keeps its colors and its focus, so a keyboard user stays on it.
MD3 has no loading button, so this is a library addition.

<SnackExample
  name="Root Native Button — Loading"
  code={`
  import { Button } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { useState } from 'react'
  import { View } from 'react-native'

  export default function App() {
    const [isSaving, setIsSaving] = useState(false)

    const save = () => {
      setIsSaving(true)
      setTimeout(() => setIsSaving(false), 2000)
    }

    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1, alignItems: 'center', justifyContent: 'center', padding: 16 }}>
            <Button loading={isSaving} onPress={save} style={{ width: 160 }}>
              Save
            </Button>
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

With no `leadingIcon`, the spinner adds the icon and its gap, so the button
gets wider while it loads. A `width` in `style` keeps the size, as above. Pass
`disabled` as well if the button must also look disabled.

## A button as a link

A button that opens a page must be a link on the web. A `Button` with an
`onPress` that calls `router.push` or `Linking.openURL` renders a `<button>`.
A crawler does not click a `<button>`, so it does not find the page.

Put the button inside Expo Router's `<Link asChild>`. `Link` gives the button
`role="link"` and `href`. That `role` replaces the button role, so the button
renders an `<a href>` on the web. A crawler follows it, and a visitor can copy
it or open it with a modifier key. On native, `Link` handles the press: it
navigates to a route, or opens an external URL with `Linking`.

```tsx
import { Button } from '@rootnative/components'
import { Link } from 'expo-router'

<Link href="/docs" asChild>
  <Button variant="text">Docs</Button>
</Link>
```

### Open a link in a new tab

On the web, `Link` opens an external URL in the same tab. Don't use
`<Link target="_blank">` for a new tab: under `asChild`, `Link` gives `target`
to the button as a plain prop, and react-native-web drops it. Give the button
`hrefAttrs`. react-native-web writes it onto the `<a>`, and Expo Router then
lets the browser open the new tab.

```tsx
<Link href="https://github.com/rootnative" asChild>
  <Button hrefAttrs={{ target: '_blank', rel: 'noopener' }}>GitHub</Button>
</Link>
```

`hrefAttrs` is web only, and native ignores it. `@rootnative/components`
declares it on the React Native `ViewProps` type, so you don't need a type
augmentation.
