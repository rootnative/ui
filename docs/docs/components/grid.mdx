# Grid

A multi-column grid that wraps its children into equal-width columns. It is built on [Row](./row), so all the Box spacing and alignment props are available.

## Usage

<SnackExample
  name="Root Native Grid — Usage"
  code={`
  import { Card, Grid, Typography } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { View } from 'react-native'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1, justifyContent: 'center', padding: 16 }}>
            <Grid columns={2} gap="sm">
              <Card variant="outlined"><Typography>Item 1</Typography></Card>
              <Card variant="outlined"><Typography>Item 2</Typography></Card>
              <Card variant="outlined"><Typography>Item 3</Typography></Card>
              <Card variant="outlined"><Typography>Item 4</Typography></Card>
            </Grid>
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

## How It Works

Grid wraps each child in a cell with `flexBasis: ${100 / columns}%`, so all columns have the same width. The `gap` prop works as gutters, not as a shrink of the cells: each cell takes half the gap as horizontal padding, and the row cancels the outer half on both edges with a negative margin. `flexBasis` stays exactly `100 / columns%`, so the row takes the full width of its parent, and the outermost cells stay flush with its edges.

## Responsive Columns

`columns` also accepts a map of [window size classes](../responsive). The grid
resolves the count again when the window crosses a breakpoint. A missing
breakpoint falls back to the nearest smaller one, so you set only the widths
where the count changes.

<SnackExample
  name="Root Native Grid — Responsive Columns"
  code={`
  import { Card, Grid, Typography } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { View } from 'react-native'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1, justifyContent: 'center', padding: 16 }}>
            <Grid columns={{ compact: 1, medium: 2, expanded: 4 }} gap="sm">
              <Card variant="outlined"><Typography>Item 1</Typography></Card>
              <Card variant="outlined"><Typography>Item 2</Typography></Card>
              <Card variant="outlined"><Typography>Item 3</Typography></Card>
              <Card variant="outlined"><Typography>Item 4</Typography></Card>
            </Grid>
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

The map requires a `compact` key, so every width resolves to a value. Use
`useBreakpointValue` from `@rootnative/core` directly when a value other than
the column count must follow the same breakpoints.

## Spanning Cells

A plain child always spans one column. Wrap a child in `Grid.Cell` to make it
span more, for an asymmetric layout such as a main area with a sidebar. The
`span` prop also accepts a breakpoint map. Grid clamps an oversized span to
the column count, so it fills the row instead of an overflow.

<SnackExample
  name="Root Native Grid — Spanning Cells"
  code={`
  import { Card, Grid, Typography } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { View } from 'react-native'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <View style={{ flex: 1, justifyContent: 'center', padding: 16 }}>
            <Grid columns={12} gap="sm">
              <Grid.Cell span={8}>
                <Card variant="outlined"><Typography>Main</Typography></Card>
              </Grid.Cell>
              <Grid.Cell span={4}>
                <Card variant="outlined"><Typography>Aside</Typography></Card>
              </Grid.Cell>
              <Grid.Cell span={{ compact: 12, medium: 6 }}>
                <Card variant="outlined"><Typography>Half on tablets</Typography></Card>
              </Grid.Cell>
            </Grid>
          </View>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

`Grid.Cell` is also exported as `GridCell` for a direct import. It sizes
itself only inside a `Grid`. Anywhere else, it warns in development and
falls back to the full width.

## Staggered entrances

A `<Stagger>` from `@rootnative/inertia` can wrap the children of the grid
directly. `Grid` looks through it, so each child still gets its own cell and
still inherits its own delay:

```tsx
import { Grid } from '@rootnative/components'
import { Motion, Stagger } from '@rootnative/inertia'

<Grid columns={{ compact: 1, medium: 2 }} gap="md">
  <Stagger interval={60}>
    {items.map((item) => (
      <Motion.View
        key={item.id}
        initial={{ opacity: 0, translateY: 12 }}
        animate={{ opacity: 1, translateY: 0 }}
      >
        <Card>{/* … */}</Card>
      </Motion.View>
    ))}
  </Stagger>
</Grid>
```

Put the `Stagger` **inside** the `Grid`, not around it. A `Grid` wrapped in a
`Stagger` is a single child of that stagger, so every card shares one delay and
the cascade disappears.
