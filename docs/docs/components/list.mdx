# List

Lists are continuous, vertical indexes of text and images.
Follows the [Material Design 3 Lists](https://m3.material.io/components/lists/overview) specification.

## Usage

<SnackExample
  name="RootNative List — Usage"
  code={`
  import { List, ListItem, ListDivider } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <List>
            <ListItem headlineText="Photos" supportingText="Jan 9, 2024" />
            <ListDivider />
            <ListItem headlineText="Recipes" supportingText="Jan 17, 2024" />
            <ListDivider />
            <ListItem headlineText="Work" supportingText="Jan 28, 2024" />
          </List>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

## List item templates

List items auto-detect their height from the content provided:

| Template | Props | Min height |
|----------|-------|------------|
| One-line | `headlineText` only | 56dp |
| Two-line | + `supportingText` or `overlineText` | 72dp |
| Three-line | + both, or multi-line `supportingText` | 88dp |

Each text line has a limit of one line by default. Set
`supportingTextNumberOfLines`, `headlineNumberOfLines` or
`overlineNumberOfLines` to show more lines, or `0` for no limit. Only a
multi-line `supportingText` changes the template. A headline or an overline
that wraps makes the item taller, and keeps its template.

## Headline

Give the list a section title with `headline`. It shows in `titleSmall` and
`onSurfaceVariant` above the items, with the same start padding as `ListItem`.
On web it renders as `<h2>`. Use `headingLevel` to change the level:

<SnackExample
  name="RootNative List — Headline"
  code={`
  import { List, ListItem } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <List headline="App preference">
            <ListItem headlineText="Language" supportingText="English" />
            <ListItem headlineText="Dark mode" />
          </List>
          <List headline="News preference">
            <ListItem headlineText="Country" supportingText="India" />
          </List>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

## Leading and trailing content

Pass any `ReactNode` as `leadingContent` or `trailingContent`:

<SnackExample
  name="RootNative List — Leading & Trailing"
  code={`
  import { List, ListItem } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { MaterialDesignIcons } from '@react-native-vector-icons/material-design-icons'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <List>
            <ListItem
              headlineText="Wi-Fi"
              supportingText="Connected"
              leadingContent={<MaterialDesignIcons name="wifi" size={24} />}
              trailingSupportingText="On"
            />
          </List>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

## Interactive items

When `onPress` is provided, the item renders as a `Pressable` with state-layer feedback:

<SnackExample
  name="RootNative List — Interactive"
  code={`
  import { List, ListItem } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { Alert } from 'react-native'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <List>
            <ListItem
              headlineText="Settings"
              onPress={() => Alert.alert('Tapped')}
            />
          </List>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

## Selection controls in a row

To let the full row toggle a `Checkbox`, `Radio` or `Switch`, give the press to
the row:

1. Put `onPress` on the `ListItem`.
2. Give the control `value` and no `onValueChange`.
3. Give the row `role` and `aria-checked`.

A control with `value` and no `onValueChange` only shows the state. It takes no
press, so a tap on the control goes to the row. It also leaves the tab order
and is hidden from assistive technology. The row announces the role and the
state in its place.

<SnackExample
  name="RootNative List — Selection controls"
  code={`
  import { Checkbox, List, ListItem, Switch } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { useState } from 'react'

  export default function App() {
    const [wifi, setWifi] = useState(true)
    const [news, setNews] = useState(false)
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <List>
            <ListItem
              headlineText="Wi-Fi"
              role="switch"
              aria-checked={wifi}
              onPress={() => setWifi(!wifi)}
              trailingContent={<Switch value={wifi} />}
            />
            <ListItem
              headlineText="Newsletter"
              role="checkbox"
              aria-checked={news}
              onPress={() => setNews(!news)}
              leadingContent={<Checkbox value={news} />}
            />
          </List>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

:::warning Give the row the role and the state

The hidden control does not announce anything. Without `role` and
`aria-checked` on the row, a screen reader announces a button and no checked
state.

:::

A disabled control is never hidden. Give the control an `onValueChange` when
it must take the press itself.

## Inset dividers

Use `insetStart` to align the divider with text that follows a leading icon:

<SnackExample
  name="RootNative List — Inset Dividers"
  code={`
  import { List, ListItem, ListDivider } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'
  import { MaterialDesignIcons } from '@react-native-vector-icons/material-design-icons'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <List>
            <ListItem
              headlineText="Item 1"
              leadingContent={<MaterialDesignIcons name="folder" size={24} />}
            />
            <ListDivider insetStart />
            <ListItem
              headlineText="Item 2"
              leadingContent={<MaterialDesignIcons name="folder" size={24} />}
            />
          </List>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>
