# Layout

Layout is a safe-area wrapper that applies the theme background color for you.

## Usage

<SnackExample
  name="RootNative Layout — Usage"
  code={`
  import { Layout, Typography } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <Layout>
            <Typography variant="headlineSmall">Inside safe area</Typography>
            <Typography variant="bodyMedium">Theme background applied automatically.</Typography>
          </Layout>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

## Immersive Mode

For a full-screen layout that extends behind the status bar:

<SnackExample
  name="RootNative Layout — Immersive"
  code={`
  import { Layout, Typography } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <Layout immersive>
            <Typography variant="headlineSmall">Immersive content</Typography>
            <Typography variant="bodyMedium">No safe area insets applied.</Typography>
          </Layout>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

## Custom Edges

Choose which safe-area edges apply:

<SnackExample
  name="RootNative Layout — Custom Edges"
  code={`
  import { Layout, Typography } from '@rootnative/components'
  import { mdiResolver } from '@rootnative/components/mdi'
  import { ThemeProvider } from '@rootnative/core'
  import { SafeAreaProvider } from 'react-native-safe-area-context'

  export default function App() {
    return (
      <SafeAreaProvider>
        <ThemeProvider iconResolver={mdiResolver}>
          <Layout edges={['top', 'bottom']}>
            <Typography variant="headlineSmall">Top + Bottom insets</Typography>
          </Layout>
        </ThemeProvider>
      </SafeAreaProvider>
    )
  }
`}
/>

By default, the `left`, `right` and `bottom` edges apply, and `top` does not, because an `AppBar` usually owns the top inset. The side insets are 0 in portrait; in landscape they keep the content clear of the notch or the Dynamic Island. In immersive mode, no edge applies. Layout reads `edges` first, and it overrides `immersive`: `<Layout immersive edges={['top']} />` applies the top inset and ignores `immersive`.

:::note

`Layout` always paints `theme.colors.background` and strips `backgroundColor`
from the `style` you pass, so the app background stays a single themed surface.
To draw a different background, nest a `Box` (or any `View`) inside it.

:::
