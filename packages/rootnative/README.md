# rootnative

A short name for [`@rootnative/cli`](https://github.com/rootnative/ui/tree/main/packages/cli), so `npx rootnative` works.

```bash
npx rootnative create my-app
npx rootnative init
npx rootnative add button card
```

This package passes every command to `@rootnative/cli`. See the [CLI docs](https://rootnative.github.io/ui/cli) for the full command reference.
